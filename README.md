# Beatboxed

An interactive music community app — rate and review songs, build custom profiles and playlists, discover new music, and get AI-assisted lyrics explanation and translation from **Beatie**.

CSC 305 team project — Imam Abdulrahman Bin Faisal University, Semester 1 2026/2027.

## Status

Design (theme, color system, full page mockups) is complete. Development starts from this scaffold.

## Start here

1. Read `CLAUDE.md` — the working context if you're using Claude Code on this repo.
2. Read `docs/roadmap.md` for the current plan and dates.
3. Read `docs/team-workstreams.md` to find your slice.
4. Copy `.env.example` to `.env.local` and fill in your own keys (never commit real keys).
5. Check `TASKS.md` for the live checklist and update it as you go.
