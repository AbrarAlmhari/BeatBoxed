How it behaves
  • Your profile: gear (Settings) top-right. ⋯ next to Edit profile opens Share profile and Copy profile link.
  • Someone else's: no gear. Follow / Following / Requested next to ⋯, which opens Share profile, Mute and Report.
  • "6 followers" opens Followers. "8 following" opens Following (people only). "Listens to…" opens Artists (artists only).
  • In every list: it scrolls; tapping a row opens that profile or artist page; each row has a working Follow / Following button; your own row has no button.
  • The header has no ratings, reviews or artists counts. The Reviews tab shows the total, and the All / Written / Ratings only chips show theirs.
  • No artists followed: the "Listens to" row is hidden.
  • Phone: the lists are bottom sheets. Computer: centred dialogs.
